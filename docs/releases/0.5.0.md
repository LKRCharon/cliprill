# Cliprill 0.5.0

## 常用内容，随时再用

- 新增「常用」Pinboards：给不同内容板设置名称和颜色，保存邮箱、地址、长段经历或图片。
- 从历史右键「固定到常用板」，或直接添加、编辑文字；支持调整顺序、跨板移动。粘贴不消耗条目，清空历史也不会删除固定内容。
- 为条目设置易识别的名称，并可隐藏预览。隐藏预览不是加密；明确打开预览、编辑或请求 MCP 内容仍可读取原文。
- ⇧⌘C 打开历史，⇧⌘V 打开常驻 FIFO 队列，新增 ⇧⌘B 打开常用板。三个快捷键均可设置。
- 历史里的 HTTP(S) 链接使用链接图标；以今天、昨天、更早分组，去掉每条的时间。精简并对齐队列底栏按钮。

## 更轻的后台与更实用的设置

- 新增均衡／灵敏／省电检查频率、图片记录开关、固定内容预览开关和登录启动。
- 默认检查间隔从 0.25 秒改为 0.5 秒。没有活动队列且记录关闭时停止轮询；活动队列保留 0.2 秒检查及每次粘贴前的安全检查。
- 隐藏面板不再重建列表，只读 MCP 请求不再刷新界面。常用内容单独存储，普通历史更新不反复序列化；缩略图缓存限制内存成本，离开图片粘贴后释放暂存图片。
- 菜单栏改用实心叠卡图标与固定 34 pt 点击区域。
- MCP 增至 21 个工具，支持常用板管理；读取默认不包含正文，写入支持版本检查及幂等重试。

## Upgrade and downloads

macOS 14 or later. Use `Cliprill-0.5.0-macOS-arm64.zip` on Apple Silicon or
`Cliprill-0.5.0-macOS-x86_64.zip` on Intel. The release also includes the exact
source archive, public signing certificate and `SHA256SUMS.txt`.

The fixed self-signed certificate and bundle ID are unchanged from 0.2.2/0.3.0.
This is not an Apple-notarized release. Existing history, queues and custom
shortcuts migrate automatically. Storage upgrades to schema 3; back up
`~/Library/Application Support/Cliprill` while the app is stopped before upgrading
if you need a downgrade path. Older versions cannot open schema 3. A rollback
requires restoring the old database as well as the old app.

See [validation](../VALIDATION.md) for automated coverage and manual-test limits.

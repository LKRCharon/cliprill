Cliprill's first public release: a native macOS clipboard manager with a FIFO paste
queue and an MCP interface. Requires macOS 14 or later.

### Included

- A menu-bar app with a panel near the pointer; **Control–Option–V** opens it.
- Plain-text history and independent queues, with duplicate entries and multiline
  items preserved. Each ordinary **Command–V** dispatches one queued item.
- Reordering, removal, pause/resume and restore-last-item controls. Copying other
  text pauses an active queue; unfinished queues reopen paused after a restart.
- Eleven MCP tools through the embedded stdio helper, with ordered writes,
  idempotency keys and revision checks.
- Local SQLite storage, application exclusions, English and Simplified Chinese UI.
- Original source under **AGPL-3.0-only**.

### Download

- `Cliprill-0.1.0-macOS-arm64.zip`: Apple Silicon.
- `Cliprill-0.1.0-macOS-x86_64.zip`: Intel.
- `cliprill-0.1.0-source.zip`: source for this release, including dependency notices.
- `SHA256SUMS.txt`: checksums for the three archives.

Unzip the matching app, move it to Applications if desired, and open it. macOS may
block the first launch because this release is ad-hoc signed, not Developer ID
signed or notarized. For a downloaded copy you trust, use **System Settings →
Privacy & Security → Open Anyway**. Enable the actual Cliprill app under
**Privacy & Security → Accessibility** to use sequential paste.

### Validation and limits

CI runs 15 Swift tests, release bundle/signature checks and packaged MCP integration
tests on native arm64 and x86_64 runners. A physical Command–V test in TextEdit on
Apple Silicon confirmed duplicate items, multiline text and completion order.

This release supports plain text and ordinary Command–V. It does not intercept
menu-based Paste or handle images/files. Queue advancement records event dispatch;
macOS cannot universally confirm that the destination app accepted the paste.
See [validation](https://github.com/LKRCharon/cliprill/blob/v0.1.0/docs/VALIDATION.md)
for the tested scope and remaining manual cases.

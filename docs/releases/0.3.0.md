Cliprill 0.3.0 refines the compact clipboard panel's search field and scroll bar.
Requires macOS 14 or later. Source is **AGPL-3.0-only**.

### What changed

- Search has a single, thin focus outline and separate spaces for its icon,
  native text field and clear button. Clearing a query no longer shifts the text.
- Search text, placeholder and caret use the native line height to align with
  the search icon. Native editing and input-method handling are preserved.
- The history and queue lists use a slim, rounded scroll thumb without the gray
  track or side borders. Dragging makes it more prominent, and Increased Contrast
  strengthens it. It retains native scrolling and hit areas and follows the
  macOS Show scroll bars preference.

### Upgrading

This release reuses the fixed signing certificate and bundle identifier from
0.2.2. History, images and queues remain in the existing application data folder.
Users upgrading from 0.2.0 or earlier should follow the one-time Accessibility
migration in the [signing guide](https://github.com/LKRCharon/cliprill/blob/v0.3.0/docs/SIGNING.md).

### Downloads

- `Cliprill-0.3.0-macOS-arm64.zip`: Apple Silicon.
- `Cliprill-0.3.0-macOS-x86_64.zip`: Intel.
- `cliprill-0.3.0-source.zip`: matching source and dependency notices.
- `Cliprill-signing-certificate.pem`: public certificate for verification.
- `SHA256SUMS.txt`: checksums for the archives and certificate.

Packages use the project's fixed self-signed identity, without Apple Developer ID
signing or notarization. If macOS blocks a trusted download, use **Privacy &
Security → Open Anyway**. The public certificate does not need to be installed
as a trusted root.

# Cliprill 0.7.0

## 安全输入下也能使用普通粘贴
- 历史和常用内容的直接粘贴不再依赖全局键盘监听，避免安全输入开启时被 Cliprill 提前拒绝。
- 仍检查辅助功能权限、目标应用和剪贴板变化；具体输入框是否接受模拟粘贴由目标应用决定。
- 新增「复制到剪贴板」，支持文字和图片；列表聚焦时可按 ⌘C。无需辅助功能权限，也不受安全输入状态限制。
- 手动复制会暂停活动队列，但不会出队或将历史条目置顶。切换到目标应用后自行按 ⌘V。
- 队列自动出队继续检查安全输入，避免无法监听按键时错误消耗内容；提示明确区分队列与普通粘贴。

## Direct paste without global keyboard monitoring
History and Pinboard paste no longer require an event tap. Secure Input therefore
does not cause Cliprill to reject these operations before attempting delivery.
Accessibility and target/clipboard checks remain. Target applications can still
reject simulated paste.

Copy to Clipboard supports text and images without Accessibility or keyboard
monitoring. It pauses active queues without consuming entries. Use the context
menu, or Command-C while the list has focus, then paste in the destination app.
Automatic queue handling retains Secure Input checks.

## Downloads
macOS 14+. Choose `Cliprill-0.7.0-macOS-arm64.zip` for Apple Silicon or
`Cliprill-0.7.0-macOS-x86_64.zip` for Intel. Source, public certificate and SHA-256
checksums are included. The fixed self-signed identity and schema 3 are unchanged.
This release is not Apple-notarized.

Validation uses isolated pasteboards and injected permission/Secure Input state;
it does not claim verified delivery into every protected input field.

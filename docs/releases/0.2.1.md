# Cliprill 0.2.1 — unpublished

The protected `v0.2.1` tag records the first fixed-certificate signing
configuration. Its release jobs did not receive the signing credentials and
stopped before producing application packages. **No public GitHub release or
download assets were published for this version.** The tag remains unchanged as
a record of that attempt.

Use [Cliprill 0.2.2](https://github.com/LKRCharon/cliprill/releases/tag/v0.2.2),
the first public release using the same fixed certificate. See its
[release notes](0.2.2.md) for downloads and the one-time Accessibility migration
from 0.2.0 or earlier.

The 0.2.1 implementation introduced certificate-pinned identities for the app and
MCP helper, stale-permission guidance, and four signing checks. Local fixed-key
checks and PR/main CI passed, but those results did not validate credential
delivery through the tag release workflow. 0.2.2 adds explicit secret declaration
and inheritance, plus an early credential-availability check.

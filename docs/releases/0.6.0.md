# Cliprill 0.6.0

## 更清晰、更顺手
- 修复选中行的内容图标和加号被系统反白、在浅色背景上难以辨认的问题。
- 历史默认隐藏来源应用名称，文字与链接改为紧凑单行；可在设置中恢复来源显示，图片保留尺寸信息。
- 单击条目后自动打开完整预览，默认等待 0.5 秒，可设置为 0.2～2 秒或关闭。敏感及隐藏内容仍需主动预览，⌘Y 保留。
- 从历史粘贴后默认置顶，可关闭；不会改变队列 FIFO 顺序。
- 设置页收窄，使用明确的标题层级与折叠的排除应用列表。
- 默认删除用空的队列，可关闭以保留队列及撤销能力。
- 中英文 README 面向用户，开发和 MCP 文档独立整理。

## Clearer browsing and faster reuse
Selected-row icons retain their intended colors. History hides source labels by default
and uses compact text rows. Click preview defaults to 0.5 seconds with an adjustable
delay; hidden saved items require explicit preview. Pasted history items move to the
top by default. Settings is narrower with clearer groups. Empty queues are removed by
default; both behaviors can be disabled.

## Downloads and upgrade
Requires macOS 14+. Download `Cliprill-0.6.0-macOS-arm64.zip` for Apple Silicon or
`Cliprill-0.6.0-macOS-x86_64.zip` for Intel. Source, public signing certificate and
SHA-256 checksums are included.

The fixed self-signed identity is unchanged. This release is not Apple-notarized.
Existing history, boards and custom preferences are preserved; schema remains 3.
The default empty-queue cleanup removes existing empty queues on upgrade.

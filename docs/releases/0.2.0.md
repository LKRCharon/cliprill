Cliprill 0.2.0 adds image history and mixed text/image paste queues, with a compact
native interface. Requires macOS 14 or later. Source is **AGPL-3.0-only**.

### What's new

- Copy screenshots or image data into history, view thumbnails and full previews,
  and queue images alongside text. Duplicate entries retain their FIFO order.
- Paste full-resolution images with transparency using PNG and TIFF. Browser image
  data takes priority over an accompanying URL. Image conversion runs in the
  background and pending pastes recheck the destination and queue state.
- A compact white panel in light appearance, matching dark appearance, public
  Lucide icons, grouped settings and a clearer search, list and queue footer.
- **Shift–Command–V** opens the panel near the pointer. Existing custom shortcuts
  are preserved; the original Control–Option–V default migrates to the new default.
- Entering **Queue** starts the selected queue and keeps the panel visible. Drag
  its blank header to move it, then focus a destination app. Each **Command–V**
  dispatches and removes one item. Returning to **History** pauses the queue.
- An Accessibility guide opens the correct System Settings page, reveals the
  running app in Finder, and detects permission changes. **Continue** returns to
  the requested workflow without sending a paste from the guide.
- MCP queue items now accept `history_id` to enqueue existing text or images.
  The same 11 tools return image metadata without embedding image pixels.

### Upgrading

Existing text history and queues migrate automatically to schema 2. Queued images
remain available after clearing history, including for restore-last-item.
Images ignored by an older build are not recoverable: copy them again after
updating. Keep a backup of both the old app and its data before downgrading;
0.1.0 cannot open the new database schema.

### Download

- `Cliprill-0.2.0-macOS-arm64.zip`: Apple Silicon.
- `Cliprill-0.2.0-macOS-x86_64.zip`: Intel.
- `cliprill-0.2.0-source.zip`: source and dependency notices for the tagged commit.
- `SHA256SUMS.txt`: checksums for all three archives.

Unzip the matching app and move it to Applications. The release is ad-hoc signed,
without Developer ID signing or notarization. If macOS blocks a trusted download,
use **System Settings → Privacy & Security → Open Anyway**. Enable Cliprill in
**Privacy & Security → Accessibility** for sequential paste.

### Validation and limits

Release CI runs 24 Swift tests, builds and verifies the signed bundle, and exercises
the packaged MCP helper and app restart on native arm64 and x86_64 runners. Image
tests use private pasteboards and check dimensions, transparency, format priority,
mixed queues, retention and migration. This iteration does not repeat visual or
physical Command–V tests into destination apps.

Images are limited to 40 megapixels and 64 MiB after PNG normalization. Animated
images use their first frame. Finder file transfers, rich text, OCR and PDF
clipboard payloads are not supported. The destination must accept image paste.
Queue advancement records event dispatch; macOS cannot universally confirm that
the destination accepted it. Restore the last item if a paste is missed.

See [image behavior](https://github.com/LKRCharon/cliprill/blob/v0.2.0/docs/IMAGES.md)
and [validation](https://github.com/LKRCharon/cliprill/blob/v0.2.0/docs/VALIDATION.md)
for details.
